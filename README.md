# INFO 

There are three sections in this repository: 

- (1) **ANALYSIS** which is the main analysis code I have been using at LHE level. This can be used as starter code but I would recomend building your own (because I think what is there is really bad) 
- (2) **DSID** which builds the DSID map for generation and proper storage
- (3) **GENERATION** which is where the generator code actually lives

(1) and (3) have their own readme for further info.
